# Profile Asset Map

This package uses local SVG assets so the hero/section animations do not depend on a third-party animation host.

- `assets/futuristic-hero.svg` — animated cyberpunk hero
- `assets/developer-core.svg` — animated AI core/orbits
- `assets/ai-network.svg` — animated agent/network graph
- `assets/learning-animation.svg` — animated learning pipeline
- `assets/footer.svg` — animated neon footer
- `assets/github-contribution-snake.svg` — generated by the snake workflow
- `profile-3d-contrib/profile-season-animate.svg` — generated by the 3D contribution workflow

The two GitHub Actions are intentionally separate so either animation can be refreshed independently.
